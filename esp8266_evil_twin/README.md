# ESP8266 Evil Twin (Captive Portal & Deauth)

基于 ESP8266 的“邪恶双子”（Evil Twin）钓鱼工具，具备高度自动化的 Deauth 攻击、多语言自适应 Captive Portal（强制门户认证）和 EEPROM 密码持久化功能。

## ✨ 主要功能

*   **⚔️ 全自动 Deauth 攻击**：选择目标 WiFi 后，自动向空气中每 200ms 发送解除认证（Deauthentication）帧，强制目标 WiFi 下的所有设备断网。
*   **🎭 完美 MAC 地址克隆**：在发起攻击时，自动克隆目标路由器的 MAC 地址（BSSID），实现物理级别的身份伪装，深度规避检测机制。
*   **🎣 强制门户认证 (Captive Portal)**：受害者连上同名的钓鱼热点后，通过 DNS 劫持强制弹出高仿的“路由器安全认证”页面。
*   **🌍 11 国语言自适应**：前端页面能根据受害者手机/浏览器的语言设置，自动无缝切换 11 种语言（中、英、日、韩、西、法、德、俄、葡、意、阿拉伯），完美适配全球设备。支持阿拉伯语 RTL 自动排版！内置容错机制，兼容所有阉割版系统自带浏览器。
*   **💾 密码历史循环记录 (EEPROM)**：捕获的密码会永久保存在 ESP8266 的闪存中。独创的 10 组密码循环缓冲区（Circular Buffer）机制，新密码自动覆盖最老密码，永不溢出、绝不崩溃。
*   **⚙️ 隐蔽后台自定义**：可通过 Web 配置页面，自由修改后台的 WiFi 名称（SSID）和密码，防止工具在不使用时被他人发现或登录。

## 🚀 使用方法

### 1. 烧录与重置
*   使用 Arduino IDE（或其他兼容环境）将代码编译并烧录至 ESP8266 模块。
*   **【重要】** 首次烧录后，请务必**长按开发板上的 Flash 按钮 (GPIO0) 3 秒以上**，直到终端提示 `Factory reset`，以初始化 EEPROM 分区，否则可能会出现密码记录乱码。

### 2. 进入后台配置
*   使用手机或电脑连接默认的后台配置热点：
    *   **默认 WiFi 名称**：`EvilTwin-Setup`
    *   **默认密码**：`12345678`
*   连接成功后，会自动弹出（或在浏览器手动访问 `http://192.168.4.1`）配置后台。
*   在此页面可以：
    *   查看所有已捕获的受害者历史密码。
    *   修改后台的 WiFi 名称和密码（增强隐蔽性）。
    *   扫描周围环境，选择要攻击的**目标 WiFi**。

### 3. 发起攻击
*   在列表中点击你要攻击的 WiFi，点击“选择”。对于隐藏网络，只需手动输入真实 SSID 即可。
*   ESP8266 会自动重启并进入**攻击模式**。
*   此时它会疯狂踢掉真实 WiFi 上的设备，并创建一个一模一样的无密码钓鱼 WiFi。受害者连上后输入密码，ESP8266 会在捕获成功 10 秒后自动关闭伪造热点，回到配置模式。
